# 🌐 Enterprise Network Infrastructure Simulation

## 📌 Overview
This repository contains the design and simulation of a secure enterprise network topology. The project focuses on business network connectivity, integrating WAN, LAN, and Ethernet configurations alongside server infrastructure and telecommunications[cite: 12]. 

## 📂 Project Files
* **`ProiectReteleFinal.pkt`**: The main Cisco Packet Tracer simulation file containing the active network topology, dynamic routing, and switching configurations[cite: 12].
* **`Schema Visio Proiect Retele.pdf`**: The exported Microsoft Visio diagram outlining the visual architecture and component connections of the basic network[cite: 12].

## 🚀 Key Features
* **Enterprise Connectivity:** Implementation of scalable LAN and WAN architectures tailored for business environments[cite: 12].
* **Network Services:** Integration of dedicated servers and telecommunication nodes[cite: 12].
* **Dynamic Routing & Switching:** Configured for high availability and secure data transmission across Ethernet links[cite: 12].

## 🛠️ Technologies & Tools
* **Simulation:** Cisco Packet Tracer
* **Architecture Design:** Microsoft Visio[cite: 12]
* **Core Concepts:** Routing, Switching, Network Security, LAN/WAN, Servers[cite: 12]
