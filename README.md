# 🌐 Enterprise Network Infrastructure Simulation

## 📌 Overview
This repository contains the design and simulation of a secure enterprise network topology. The project focuses on business network connectivity, integrating WAN, LAN, and Ethernet configurations alongside server infrastructure and telecommunications. 

## 📂 Project Files
* **`ProiectReteleFinal.pkt`**: The main Cisco Packet Tracer simulation file containing the active network topology, dynamic routing, and switching configurations.
* **`Schema Visio Proiect Retele.pdf`**: The exported Microsoft Visio diagram outlining the visual architecture and component connections of the basic network.

## 🚀 Key Features
* **Enterprise Connectivity:** Implementation of scalable LAN and WAN architectures tailored for business environments.
* **Network Services:** Integration of dedicated servers and telecommunication nodes.
* **Dynamic Routing & Switching:** Configured for high availability and secure data transmission across Ethernet links.

## 🛠️ Technologies & Tools
* **Simulation:** Cisco Packet Tracer
* **Architecture Design:** Microsoft Visio
* **Core Concepts:** Routing, Switching, Network Security, LAN/WAN, Servers
